# Human Detection Alert System

This project detects humans using a webcam through OpenCV.  
When a human is detected, an **email alert** is automatically sent.

---

##  Features
- Detects humans using Haar Cascade.
- Sends email alert automatically (Gmail SMTP).
- Works in real-time through webcam.
